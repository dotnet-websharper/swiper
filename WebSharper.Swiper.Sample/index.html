What this sample exercises

  • Swiper construction from a selector, SwiperOptions with core and module options.
  • Module imports: SwiperModule.Navigation, Pagination, Scrollbar, Keyboard, Mousewheel, A11y, Autoplay, Zoom, Manipulation, Thumbs, FreeMode, Grid and every effect module.
  • Typed events through SwiperEventHandlers (Init, SlideChange, Progress, ZoomChange, AutoplayStart/Stop, …).
  • Instance API: SlideNext/SlidePrev, SlideTo, ChangeDirection, Update, AppendSlide, RemoveSlide, Destroy, Enable/Disable, SlidesPerViewDynamic, GetSlideIndex.
  • Module APIs: Navigation.NextEl, Pagination.Bullets, Autoplay.Running/Start/Stop, Zoom.In/Out/Scale, Keyboard.Enable/Disable, Thumbs.Update, Grid.Rows.
